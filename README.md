# AppStash Centralized Checkout Hub 💳

Trang trung tâm thanh toán tự động qua mã VietQR (tích hợp SePay) dành cho các tiện ích mở rộng (Chrome Extensions) thuộc hệ sinh thái AppStash.

## 🚀 Tính năng
- Tự động nhận diện ứng dụng từ tham số URL (`?app=promptstash`).
- Tạo mã VietQR động theo thời gian thực dựa trên Email của khách hàng.
- Tương thích tốt với SePay Webhook & Make.com để tự động trả License Key.
- Hosting siêu tốc trên GitHub Pages.

## 🔗 Cú pháp đường dẫn
- **PromptStash Pro:** [`https://<ten-domain>/?app=promptstash`](https://chromewebstore.google.com/detail/promptstash-pro/njfbngmadlpochmbboikmehkoffkhicm?pli=1)
